CSV to XLSX Converter 1.0.0
===========================

CSV・TSVファイルを、文字化けさせず、値を勝手に変えさせずにExcelで開くためのMacアプリです。
元のファイルは変更しません。


■ 使い方

1. 「CSV to XLSX Converter.app」をダブルクリックして起動します。
   （アプリケーションフォルダに移してもかまいません）
2. CSVファイルをウインドウにドロップするか、「ファイルを選択…」で選びます。
   複数のファイルをまとめて扱えます。.csv / .tsv は、Dockのアイコンへのドロップや、
   Finderの「このアプリケーションで開く」からも渡せます（この2つの経路は未確認です）。
3. 変換したファイルが元のファイルと同じフォルダに保存され、Excelで開きます。

対象：拡張子が .csv / .tsv / .txt のファイル（大文字・小文字は区別しません）


■ 設定（ウインドウ内で選び、次回以降も記憶します）

出力形式
  Excelブック（.xlsx）… 推奨。セルを「文字列」「数値」「日付・時刻」の正しい型で保存します。
                        「'」は付かず、画面にも出ません。
  CSV（UTF-8・BOM付き）… 従来どおりのCSV。Excelに変換させたくない値の先頭に「'」を付けます。
                        Excelの仕様上、この「'」は画面に見えます。

12桁以上の数字（JANコード、法人番号、マイナンバーなど、数字だけの値）
  文字列として扱う … 初期設定。桁をそのまま表示します。
  数値として扱う   … 数値にします（xlsxでは指数表記にならない表示形式を付けます）。
                     16桁以上はExcelの精度（15桁）を超えるため、この設定でも文字列のままです。
                     マイナス付きの12桁以上の値、カンマ区切りの値（123,456,789,012など）は
                     金額とみなし、設定にかかわらず数値にします。

文字コード … 自動判定（初期設定）／UTF-8／Shift_JIS（CP932）／EUC-JP／UTF-16
区切り文字 … 自動判定（初期設定）／カンマ／タブ／セミコロン
変換したらExcelで開く … オフにすると、保存だけ行います。


■ 保存先とファイル名

・元のファイルと同じフォルダに「元の名前_excel.xlsx」（CSV出力なら「元の名前_excel.csv」）で保存します。
・同じ名前のファイルがすでにあり、中身がまったく同じなら、新しく作らずにそれを開きます。
  中身が違えば（設定を変えた、Excelで編集した等）、「元の名前_excel 2.xlsx」のように番号を付けます。
  既存のファイルを上書きすることはありません。
・元のフォルダに書き込めない場合は、「ダウンロード/CSV to XLSX Converter」に保存し、そのことを知らせます。


■ 値の扱い（xlsx出力の場合）

方針：はっきり数値・日付と言える値だけを数値・日付にし、それ以外は元の文字列のまま残します。

数値にするもの
  12345 → 数値　　-42 → 数値（マイナスの整数も数値のまま）　　-1.25 → 数値
  12.50 → 数値（表示は 12.50 のまま）　　1,234,567 → 数値（3桁区切りで表示）
  12.5% → 数値（0.125、表示は 12.5%）

日付・時刻にするもの（年が4桁で、実在する日付のみ）
  2026/10/20、2026-10-20、2026/1/5、2026年10月20日 → 日付（元の書き方に近い表示形式）
  2026/10/20 12:34、2026-10-20 08:05:30 → 日付と時刻
  8:05、08:05、23:59:59 → 時刻　　37:30 → 時間の長さ（[h]:mm）

文字列のまま残すもの（Excelに任せると変わってしまう値）
  00123、000042 … 先頭のゼロ
  4901234567894 … 12桁以上の数字（設定による）
  1234567890123456 … 16桁以上の数字
  +81312345678、+7 … 先頭の「+」
  1E3、1.2e-03 … 指数表記に見える型番など
  1-2、1-2-3、10/20、2026/10、10月20日 … 番地・月日など、年月日がそろわない日付風の値
  2026/2/29、1899/12/31 … 実在しない日付、1900年3月より前の日付
  =1+1、@SUM(A1)、-abc … 数式に見える値（計算されません）
  ０１２３、１２３ … 全角の数字
  上記以外の文字（りんご、001A、ｶﾀｶﾅ など）

このほか
  ・セル内の改行は保持し、そのセルは折り返して表示します。
  ・列幅は内容に合わせて自動で設定します。シート名は元のファイル名です。
  ・「数値が文字列として保存されています」の緑の三角は表示しない設定にしています。

CSV出力の場合は、上の「文字列のまま残すもの」（最後の「上記以外の文字」を除く）の先頭に「'」を付けます。
数値・日付にするものには何も付けず、Excelの読み込みに任せます。
12桁以上の数字を「数値として扱う」にしたCSVでは、Excelが指数表記で表示することがあります（結果欄で注意します）。


■ 文字コードの自動判定

1. 先頭のBOMで判断（UTF-8、UTF-16LE、UTF-16BE）
2. BOMのないUTF-16（ゼロバイトの偏りで判断）
3. UTF-8として正しく読めればUTF-8
4. Shift_JIS（CP932）とEUC-JPのうち、正しく読める方。両方読める場合は、ひらがな・カタカナの
   出現数で判断し、判断がつかないときはShift_JISとして読んで注意を表示します。
5. どれでも正しく読めない場合は、読めない文字を「�」に置き換えて変換し、必ず注意を表示します。

・UTF-8のBOMが付いているのに本文がShift_JISというファイルも、本文の文字コードで読みます。
・自動判定が合わないときは、「文字コード」で指定してください。


■ 注意と制約

・Excelの上限（1,048,576行・16,384列・1セル32,767文字）を超えた分は含めず、注意を表示します。
・ファイル全体をメモリに読み込みます。10万行のCSVで約1秒が目安です（開発時のMac〔Apple Silicon〕での実測）。
・「¥1,000」「1,000円」のような通貨記号付きの値、「2026-10-20T12:34」のような書き方は文字列のままです。
・「1:02」のような値は時刻として扱います。
・Excelが見つからない場合は、既定のアプリで開き、その旨を表示します。
・アプリはアドホック署名で、Appleの開発者署名・公証はしていません。自分でビルドしたMacでは
  そのまま起動できます。ダウンロードしたアプリは、初回だけ「システム設定」→「プライバシーと
  セキュリティ」で「このまま開く」をクリックする必要があります（手順は README.md を参照）。


■ 動作確認（2026年10月20日、開発者のMac〔macOS 26.6.2・Apple Silicon〕で実施）

・変換エンジンの自動テスト132項目に合格（文字コード判定、区切り文字判定、セルの判定、保存とファイル名、
  書き込めないフォルダの扱い、10万行の処理時間）。
・実際のExcelで表示を確認：Shift_JIS・EUC-JP・UTF-16（タブ区切り）・UTF-8の見本ファイル、
  ドラッグ＆ドロップ、同じファイルを再度開いたときの再利用、内容が違うときの番号付き保存、
  CSV出力、12桁以上の数字を数値にする設定。
  見本ファイルは「テスト用CSV」フォルダにあります。
・未確認：Dockのアイコンへのドロップ、Finderの「このアプリケーションで開く」、Intel Mac・macOS 13〜15での動作。


■ ソースと再ビルド

Sources/Core/  変換エンジン（文字コード・CSVの読み取り・セルの判定・xlsxの書き出し）
Sources/App/   画面とExcelの起動
Resources/     文字コード表、アイコン、Info.plist
Tests/         自動テストと見本データ
Tools/         文字コード表と見本データの生成スクリプト（開発用。再ビルドには不要）

再ビルドは「ビルド.command」をダブルクリックするか、ターミナルでこのフォルダに移動して ./build.sh を実行します。
配布用のZIPとそのSHA-256も dist/ に作ります。
Xcodeのコマンドラインツールが必要です。経過は build.log に記録されます。
