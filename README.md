# CSV to XLSX Converter

CSV・TSVファイルを、文字化けさせず、値を勝手に変えさせずにMicrosoft Excelで開くためのMacアプリです。元のファイルは変更しません。

Shift_JISのCSVがExcelで文字化けする、先頭の0が消える、JANコードが「4.90123E+12」になる、「1-2」が「1月2日」になる、といった問題を避けるために作りました。CSVを読み込んで、セルを「文字列」「数値」「日付」の正しい型にしたExcelブック（.xlsx）を作り、Excelで開きます。

## できること

- **文字コードの自動判定**：UTF-8（BOMあり・なし）、Shift_JIS（CP932）、EUC-JP、UTF-16。UTF-8のBOMが付いているのに本文がShift_JIS、というファイルも読めます。読めない文字があったときや判別しきれないときは注意を表示します。
- **区切り文字の自動判定**：カンマ、タブ、セミコロン。
- **Excelに変えさせない**：先頭のゼロ（00123）、12桁以上の数字、「+」で始まる値、「1E3」のような型番、「1-2」「10/20」のような値、全角の数字、数式に見える値は、文字列のまま残します。「'」は付けません。
- **数値・日付は正しく扱う**：マイナスの数、小数、3桁区切り、パーセントは数値に、「2026/10/20」のように年月日がそろった値は日付にします。元の表示（12.50、1,234,567、2026/1/5 など）に近い表示形式を付けます。
- **12桁以上の数字**：初期設定は文字列（全桁表示）。設定で数値にも切り替えられ、その場合も指数表記になりません。
- **CSVでの出力も可能**：UTF-8（BOM付き）のCSVを出力し、変換させたくない値の先頭に「'」を付けます（Excelの仕様上、「'」は画面に見えます）。
- **上書きしない**：出力は元のファイルと同じフォルダに「元の名前_excel.xlsx」で保存します。同じ内容の出力があればそれを開き、内容が違えば番号を付けて別に保存します。
- 複数ファイルのまとめて変換、ドラッグ＆ドロップに対応。変換処理は外部のサービスやプログラムを使いません。

## 動作環境

- macOS 13以降（Apple Silicon・Intel 両対応のUniversalビルド）
- Microsoft Excel（ない場合は、変換したファイルを既定のアプリで開きます）
- ビルドに Xcode コマンドラインツール（Xcode本体は不要）

確認済みの環境は macOS 26.6.2・Apple Silicon のみです。Intel Mac と macOS 13〜15 では動作を確認していません。

## ダウンロード

ビルド済みのアプリは [Releases](https://github.com/moriyakeiichi/csv-to-xlsx-converter/releases) にあります。

1. 最新版の `CSV-to-XLSX-Converter-<版>.zip` をダウンロードして開きます。「CSV to XLSX Converter <版>」フォルダの中に、アプリ、はじめに.txt、LICENSE が入っています。
2. 「CSV to XLSX Converter.app」をアプリケーションフォルダに移します。
3. 初めて起動するときだけ、次の手順が必要です。このアプリはAppleの公証を受けていないため、macOSが起動を止めます。
   1. 「CSV to XLSX Converter」をダブルクリックします。警告が表示されたら「完了」をクリックします（「ゴミ箱に入れる」は選ばないでください）。
   2. アップルメニューの「システム設定」を開き、サイドバーの「プライバシーとセキュリティ」をクリックします。
   3. 右側を下にスクロールし、「セキュリティ」の項目に表示される「このまま開く」（表示によっては「開く」）をクリックします。このボタンは、起動を試してから約1時間だけ表示されます。
   4. 確認が表示されたら「このまま開く」をクリックし、ログインパスワードを入力して「OK」をクリックします。

   2回目からは、ダブルクリックで普通に起動できます。手順の詳細は Apple のサポートページ「[開発元が不明なMacアプリを開く](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)」を参照してください。

ダウンロードしたZIPが改ざんされていないかは、リリースのページに記載したSHA-256と、ターミナルで次のコマンドを実行した結果が一致するかで確かめられます。

```
shasum -a 256 ~/Downloads/CSV-to-XLSX-Converter-1.0.0.zip
```

## ソースからビルド

自分のMacでビルドすると、上の「このまま開く」の手順は不要です（1〜2分です）。

1. Xcode コマンドラインツールが入っていなければ、ターミナルで次を実行して入れます。

   ```
   xcode-select --install
   ```

2. このリポジトリを取得します（「Code」ボタンの「Download ZIP」でもかまいません）。

   ```
   git clone https://github.com/moriyakeiichi/csv-to-xlsx-converter.git
   ```

3. ターミナルでフォルダに移動して、ビルドします。

   ```
   cd csv-to-xlsx-converter
   bash build.sh
   ```

   Finderで「ビルド.command」をダブルクリックしても同じです。ただし、ZIPでダウンロードした場合は、macOSのセキュリティ確認でダブルクリックが止められることがあります。そのときはターミナルで実行してください。

4. フォルダに「CSV to XLSX Converter.app」ができます。アプリケーションフォルダに移して使ってください。

ビルドでは、最初に変換エンジンの自動テストを実行し、合格した場合だけアプリを作ります。配布用のZIPも `dist/` に作ります。経過は `build.log` に記録されます。

## 使い方

1. 「CSV to XLSX Converter」を起動します。
2. CSVファイルをウインドウにドロップするか、「ファイルを選択…」で選びます。
3. 変換したファイルが保存され、Excelで開きます。

ウインドウで、出力形式（xlsx／CSV）、12桁以上の数字の扱い、文字コード、区切り文字を指定できます。設定は次回も記憶します。

## 変換のルール（xlsx出力）

| 元の値 | Excelでの扱い |
| --- | --- |
| `12345` `-42` `-1.25` `12.50` `1,234,567` `12.5%` | 数値 |
| `2026/10/20` `2026-10-20` `2026年10月20日` | 日付 |
| `2026/10/20 12:34` | 日付と時刻 |
| `08:05` `23:59:59` | 時刻 |
| `37:30` | 時間の長さ |
| `00123` `+81312345678` `1E3` `1-2` `10/20` `2026/2/29` `=1+1` `０１２３` | 文字列（変換しない） |
| `4901234567894`（12〜15桁の数字だけの値） | 文字列（設定で数値にも） |
| `1234567890123456`（16桁以上） | 常に文字列（Excelの精度は15桁のため） |

詳しいルール、文字コードの判定順、注意点は [はじめに.txt](はじめに.txt) を参照してください。見本のファイルは [テスト用CSV](テスト用CSV) にあります。

## 制約

- Excelの上限（1,048,576行・16,384列・1セル32,767文字）を超えた分は含めず、注意を表示します。
- ファイル全体をメモリに読み込みます。10万行で約1秒が目安です。
- 「¥1,000」「1,000円」のような通貨記号付きの値は文字列のままです。
- 「1:02」のような値は時刻として扱います。
- アプリはアドホック署名で、Appleの開発者署名・公証はしていません。ダウンロードしたアプリを初めて起動するときは、上の「このまま開く」の手順が必要です。

## ファイル構成

```
Sources/Core/   変換エンジン（文字コード判定・CSVの読み取り・セルの判定・xlsxの書き出し）
Sources/App/    画面とExcelの起動（AppKit）
Resources/      文字コード表、アイコン、Info.plist
Tests/          自動テストと見本データ
Tools/          文字コード表・見本データの生成スクリプト（Python。ビルドには不要）
build.sh        テストとビルド
```

CP932・EUC-JPの文字コード表は、Python標準のコーデックから `Tools/make_tables.py` で生成したものです。実行時にPythonは使いません。
